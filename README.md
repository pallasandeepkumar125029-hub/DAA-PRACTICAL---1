# DAA-PRACTICAL---1

Bubble Sort: 
Summary:
This program implements the Bubble Sort algorithm in Python. It sorts the elements by comparing two adjacent values and swapping them if they are in the wrong order. The process continues until the entire list is sorted. The execution time is also measured to understand its performance.

Conclusion:
Bubble Sort is simple and easy to understand, making it a good algorithm for beginners. However, it requires many comparisons and swaps, so it is not suitable for large datasets. It works best for learning the basic idea of sorting.



Selection Sort:
Summary:
This program implements the Selection Sort algorithm. It repeatedly finds the smallest element from the unsorted part of the list and places it in its correct position. The program also records the execution time for performance analysis.

Conclusion:
Selection Sort is easy to implement and performs fewer swaps than Bubble Sort. Although it works correctly, it takes more time for large datasets because it always checks every remaining element before making a swap.



Insertion Sort:
Summary:
This program uses the Insertion Sort algorithm to arrange elements in ascending order. Each element is inserted into its correct position within the already sorted part of the list. The execution time is measured to observe its efficiency.

Conclusion:
Insertion Sort is simple and works well for small or nearly sorted datasets. It is faster than Bubble Sort in many cases, but its performance decreases when sorting large amounts of data.



Merge Sort:
Summary:
This program implements the Merge Sort algorithm using the divide-and-conquer approach. The list is divided into smaller parts, sorted separately, and then merged into one sorted list. The execution time is measured to compare its efficiency with other sorting algorithms.

Conclusion:
Merge Sort is an efficient sorting algorithm that performs well even with large datasets. Although it uses extra memory during the merging process, it provides faster and more consistent performance than simple sorting methods.



Quick Sort:
Summary:
This program implements the Quick Sort algorithm. It selects a pivot element, places smaller values on one side and larger values on the other, and repeats the process until the entire list is sorted. The execution time is measured to evaluate its performance.

Conclusion:
Quick Sort is one of the fastest sorting algorithms for most datasets. It is widely used because of its speed and efficiency. This implementation helped me understand how partitioning improves sorting performance compared to simpler algorithms.
