SUMMARY:
The program sorts numbers using Heap Sort.

It asks the user to enter numbers separated by spaces.

It shows the original list, the sorted list, and how long the sorting took.

Heap Sort works by making a Max Heap (largest number at the top) and then arranging numbers in order.

CONCLUSION:
Heap Sort is faster and more reliable than Bubble Sort.

It always runs in about O(n log n) time, no matter the case.

This makes it good for sorting large lists of numbers.

The program is simple to use and helps you see both the result and the speed of the algorithm.
