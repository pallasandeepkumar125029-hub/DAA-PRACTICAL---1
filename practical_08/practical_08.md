BREADTH FIRST SEARCH (BFS)
INTRODUCTION:
bfs.py implements the Breadth First Search algorithm, which explores nodes level by level using a queue.

SUMMARY:
BFS is useful for exploring all neighbors of a node before moving deeper. It is commonly applied in shortest path problems (for unweighted graphs) and network analysis.

CONCLUSION:
Use BFS when you need to explore nodes layer by layer or ensure breadth exploration across a graph.

DEPTH FIRST SEARCH (DFS)
INTRODUCTION:
dfs.py implements the Depth First Search algorithm, which explores as far as possible along one branch before backtracking.

SUMMARY:
DFS is effective for exploring deep structures, detecting cycles, and performing tasks like topological sorting. It can be implemented recursively or iteratively with a stack.

CONCLUSION:
Use DFS when you need to explore depth, detect cycles, or perform ordering tasks in a graph.
